We first ran the teacher script without changes as the baseline. We then compared two implementations: the teacher script with small, logged edits so each setting can be switched, and our own model built from the paper with energy-balance checks. The paper states the hydrogen formula two ways, so we tested both. Finally we searched every combination of 13 settings the paper does not pin down: 1,600 physical and 240 financial, which is 384,000 combinations per run and four runs. Financial settings only change LCOE, so each physical setting is simulated once per design. One setting has to serve all three designs, and a target passes if it is within 10% of the paper.

Takeaway

What we learned, and why

TakeawayReasoning
1The gap is not a tuning problem
1.5 million combinations give at best 4 of 9 targets and no full design. The best settings also differ between the two models, so no single "true" setting emerges.
2DPSP is the blocker
Every best run has too few deficits (0.05–0.79% vs 0.90–0.97%). With the Excel data, daytime surplus refills storage every day. No physical setting recreates the paper's Mode 1 dip near hour 4450 (paper load factor 0.71, lowest found 0.88).
3LCOE gap points to a missing cost
Teacher LCOE is 27–30% low in all three designs, a uniform shift. It closes only when a separate balance-of-plant cost is added, which is an unverified proxy.
4The paper most likely uses the minimum H2 formula
Addition removes all deficits in the teacher script and leaves DPSP and EWP unchanged in our model. Paper text and teacher code both use minimum.
Conclusion: the remaining gap most likely comes from input data or model details not stated in the paper.
Next: confirm the error definition with the professor and request the authors' hourly data and dispatch rules.
In percentage points, the best teacher-script run is within 0.82 pp on every DPSP and EWP value.4 / 4
First, more tuning will not close the gap: after 1.5 million combinations the best result passes four of nine targets and no complete design, and the two models prefer different settings. Second, DPSP is the main blocker. Our runs always have fewer deficits than the paper because, with the Excel data, the daytime surplus refills storage every day. None of the 1,600 physical settings reproduces the load-factor dip the paper shows near hour 4450. Third, the teacher LCOE is low by a nearly constant 27 to 30 percent across all designs, which points to a missing cost block rather than a dispatch difference. Fourth, the addition formula makes things worse, which supports the minimum formula used in the paper text and the teacher code. Note that errors here are relative. Measured in percentage points, the best teacher-script run is within 0.82 points on every DPSP and EWP value, so the error definition matters for how we judge success.
